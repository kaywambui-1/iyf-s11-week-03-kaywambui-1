My Story

Hi, I'm Christine — a beginner web developer learning HTML, CSS, JavaScript, and Git through hands-on, project-based coursework. I'm still early in my coding journey, but I'm building real things step by step: pages, layouts, and small interactive features, one project at a time.

That background taught me to care about the details — clean structure, thoughtful presentation, and getting the fundamentals right before adding polish. I'm now applying that same mindset to programming as I grow my skills.
